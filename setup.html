Set up your computer

You will install the LeRobot software and everything it depends on. Nothing here needs the robot, so you can do it before the kit is even open.

30–60 minutes, mostly downloadsYou need: a computer, internet, about 10 GB of free disk space

Pick your system once here. Every page remembers your choice.

Windows 10 or 11. We use Windows directly (not "WSL"), because connecting USB devices to WSL takes extra administrator steps that are not worth it for beginners.

A Mac with an Apple Silicon chip (M1 or newer) and macOS 14 or newer; macOS 15 or newer if you want to use the Mac's GPU for training. Older Intel Macs are not supported by the current versions of the software LeRobot depends on.

Ubuntu or a similar distribution. This is the system LeRobot's own documentation is written for.

First, four ideas

The terminal

A terminal is a window where you type commands as text and the computer answers in text. It looks old-fashioned, but it is how almost all robotics and AI software is run, because a typed command can say exactly what you want in one line. You type a command, press Enter, and wait for the prompt to come back.

Python and packages

LeRobot is written in Python, a programming language. You will not write Python in this course, but you need Python installed to run it. Python programs are built from packages: bundles of code that others have written. LeRobot itself is a package, and it relies on dozens of others (for example PyTorch, which does the neural-network maths).

Environments

Different projects need different versions of packages, and they can clash. An environment is a private folder with its own Python and its own packages, separate from everything else on the computer.

Analogy

An environment is like a separate pencil case for each school subject. What you put in the art case does not mess up the maths case. If the art case becomes a disaster, you throw it away and make a new one, and maths is untouched.

The tool that creates environments is called conda. We install it through a free distribution named Miniforge, which is what the LeRobot docs recommend.

The Hugging Face Hub

The Hub is a website for sharing datasets and AI models, a bit like a cloud drive made for machine learning. LeRobot uploads your recordings there, and training (on your computer or in the cloud) downloads them from there.

Install everything

  1. Install Miniforge

    Go to github.com/conda-forge/miniforge, download Miniforge3-Windows-x86_64.exe and run it. Accept the default options.

    Then open the Start menu and launch Miniforge Prompt. This is your terminal for the whole course. Conda only works in this window, not in the ordinary Command Prompt or PowerShell.

    Go to github.com/conda-forge/miniforge, download the macOS installer for Apple Silicon (the .pkg file) and run it.

    Then open the Terminal app: press Cmd+Space, type Terminal, press Enter. If it was already open, close and reopen it.

    Open a terminal (Ctrl+Alt+T on Ubuntu) and run these two lines from the LeRobot docs:

    wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh

    Answer yes to the questions, then close and reopen the terminal.

    Check it worked:

    conda --version
    conda 26.5.3

    Your version number will differ. Any number means success. "Command not found" means the terminal has not picked up conda yet: close and reopen it (on Windows, make sure you are in Miniforge Prompt).

  2. Create the environment

    conda create -y -n lerobot python=3.12
    conda create -y -n lerobot python=3.12

    Now step inside it:

    conda activate lerobot

    Your prompt should now start with (lerobot).

    You will do this every time

    Every time you open a new terminal, type conda activate lerobot first. If a LeRobot command says "command not found" or "is not recognized", the cause is nearly always that (lerobot) is missing from the prompt.

  3. Install ffmpeg

    conda install -y ffmpeg -c conda-forge
    Why?

    Your camera will record 30 pictures every second. Stored as separate images, fifty demonstrations would fill many gigabytes. ffmpeg is a program that compresses pictures into video files (and unpacks them again for training), making them many times smaller. LeRobot uses it behind the scenes.

  4. Windows with an NVIDIA graphics card only: install the GPU version of PyTorch

    First find out whether you have an NVIDIA GPU:

    nvidia-smi

    If a table appears naming a card (for example "GeForce RTX 4060"), you have one. If you get "not recognized", you do not: skip this step.

    With an NVIDIA card, run this before installing LeRobot:

    pip install --index-url https://download.pytorch.org/whl/cu132 torch torchvision
    Why?

    PyTorch comes in two builds: one that can use an NVIDIA graphics card (through NVIDIA's system called CUDA) and one that only uses the main processor. On Windows, the default download is the processor-only build, even if you own a powerful graphics card. This command fetches the GPU build from PyTorch's own server instead.

    The official LeRobot docs do not cover this case, so this command is our best reading of PyTorch's download server, not an official instruction. Step 7 checks whether it worked. If it did not, update your NVIDIA driver and try again.

    Nothing to do. On a Mac, the normal install already supports the Apple GPU.

    Nothing to do if your NVIDIA driver is recent (version 580.65 or newer; check with nvidia-smi). The normal install already includes GPU support. With an older driver, update the driver, or see the "CUDA" section of the official installation page.

  5. Install LeRobot

    pip install "lerobot[core_scripts,feetech,training]"
    pip install "lerobot[core_scripts,feetech,training]"

    This downloads a few gigabytes and takes several minutes. Lines of text will scroll past; that is normal. It is finished when the prompt returns.

    The quotation marks matter: without them some terminals misread the square brackets.

  6. Check the installation

    lerobot-info

    It prints a report. Look for these lines:

    - LeRobot version: 0.7.0
- Python version: 3.12.x
- FFmpeg version: 8.x
- PyTorch version: 2.15.0
- Is PyTorch built with CUDA support?: True      (NVIDIA cards only; False is expected otherwise)

    Version numbers may be newer than these. This course was written for LeRobot 0.7.0 (November 2026).

  7. Find out where you will train

    Training needs a GPU. Run the check for your system:

    python -c "import torch; print(torch.cuda.is_available())"
    python -c "import torch; print(torch.backends.mps.is_available())"
    python -c "import torch; print(torch.cuda.is_available())"
    ResultWhat it meansYour training plan (chapter 12)
    True on Windows or LinuxNVIDIA GPU is readyTrain on this computer
    True on a MacApple GPU is readyPossible but slow (6–14 hours); the cloud is faster
    FalseNo usable GPUTrain in the cloud. This computer is still fine for everything else
    Why does training need a GPU?

    Training a neural network means doing the same simple multiplication billions of times. A normal processor (CPU) is like a few very clever workers; a graphics card (GPU) is like thousands of simple workers who can all multiply at once. Graphics cards were built to compute millions of pixels in parallel for games, which happens to be the same kind of work. Recording and teleoperating do not train anything, so they need no GPU.

  8. Create a Hugging Face account and log in

    Go to huggingface.co/join and create a free account. Choose your username carefully: it becomes part of the name of everything you upload. (If you are under the age the site requires, ask your teacher to use a class account.)

    Then create an access token, a long password made for programs:

    1. Open huggingface.co/settings/tokens and click "Create new token".
    2. Choose the token type Write, give it a name such as lerobot, and create it.
    3. Copy the token (it starts with hf_). You will not be able to see it again.

    In your terminal:

    hf auth login

    Paste the token when asked and press Enter. Nothing appears while you paste; that is a safety feature, not a fault. Then confirm:

    hf auth whoami
    ✓ Logged in
  user: your-username
    Treat the token like a password

    Anyone who has your token can upload and delete things as you. Never put it in a chat, a screenshot or a shared document.

    Why "Write"?

    A read token can only download. LeRobot needs to upload your dataset and your trained policy, so the token must have write permission.

A note on commands in this course

LeRobot's official documentation is written for macOS and Linux. Three small things differ on Windows, and this course handles them for you:

macOS / LinuxWindows
Long commandsSplit over lines with \ at each line endWritten on one long line
Port names/dev/tty.usbmodem… or /dev/ttyACM0COM3, COM5 …
Your usernameThe docs write ${HF_USER}, a variable. In this course you simply type your own username where you see YOUR_NAME. It is less clever, but it works the same on every system and you always know what the command says.

The official docs' command for filling HF_USER automatically currently returns an empty name with recent versions of the login tool, which is one more reason to type it yourself.
